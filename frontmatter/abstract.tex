\begin{abstract}
	En este documento se expone el resultado del análisis de calidad geométrica ejecutado sobre las tablas geoespaciales de la base de datos (\code{BD_SIGPAC_NORM}). Dicha base de datos fue obtenida mediante una derivación de la base de datos originalmente consumida por la aplicación del FEGA. En primer lugar, se describe el procedimiento de auditoría no destructiva aplicado y los defectos geométricos y topológicos que se buscan, con su clasificación por severidad. A continuación se presentan los resultados obtenidos para la primera región analizada (el País Vasco). El informe está estructurado para incorporar progresivamente los resultados de otras regiones a medida que se auditen sus correspondientes bases de datos. Las cifras proceden de un entorno local concreto y deben interpretarse como órdenes de magnitud.
\end{abstract}
